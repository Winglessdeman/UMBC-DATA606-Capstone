# Project Documentation

This directory contains the supporting documentation, research proposal,
final report, and visualizations for the UMBC DATA606 Capstone Project.

## Project Title

Identifying Elevated HbA1c Using Non-Laboratory Predictors:
A Machine Learning Approach Using NHANES Data (2011–2018)

## Documentation

| Document | Description |
